# Statistical Analysis Plan

## 1. Univariate Analysis
- **Distributions**: Histograms and Kernel Density Estimation (KDE) for $P$, $\dot{P}$, $B_s$, $\tau$.
- **Log Scale Transformations**: Physical parameters spanning multiple orders of magnitude ($P, \dot{P}, B_s$) must be analyzed in $\log_{10}$ space.
- **Summary Statistics**: Mean, median, standard deviation, interquartile range (IQR), minimum, maximum.

## 2. Bivariate & Population Correlations
- **$P - \dot{P}$ Diagram**: The fundamental pulsar population plot showing evolution tracks, death lines, and millisecond pulsar sub-populations.
- **Galactic Latitude Distribution**: Evaluation of scale height above the Galactic plane.

## 3. Missing Value Analysis
- Quantification of missingness rates per parameter (e.g. mass completeness vs rotational completeness).
